# README file for Autism IPP Project

Data preparation and analysis code for the Autism IPP paper.

**Primary author:** Devin Byers
**ISCC Consultant:** Jess Brantez

## Project structure

```
Project folder/
├── Code/
│   ├── autism_ipp_recode.qmd       1. recodes original data to match V11 (10.20.26)
│   ├── autism_ipp_imputation.qmd   2. imputes missing data
│   ├── autism_ipp_analysis.qmd     3. runs the analyses
│   └── styles.css                  styling for the rendered HTML
├── Data/                           data files (not tracked in Git)
│   ├── Original Data.xlsx          original data
│   ├── autism_ipp_recoded.rds      created by step 1
│   └── autism_ipp_imputed.rds      created by step 2
└── Output/                         results from the analysis
```

## Data

Data files are not included in this repository.
To run the code, place `Original Data.xlsx` in the `Data/` folder.
The `.rds` files are created when you run the code.
Devin Byers has the original data excel file.

## Requirements

- R (version 4.4 or later)
- [Quarto](https://quarto.org)
- R packages: `tidyverse`, `readxl`, ``

Install the packages once in R:

```r
install.packages(c("tidyverse", "readxl", ""))
```

## Usage

Run the files in order. Each one uses the output of the one before it.

Open each `.qmd` file in RStudio and click **Render**, or run from the project folder:

```bash
quarto render Code/autism_ipp_recode.qmd
quarto render Code/autism_ipp_imputation.qmd
quarto render Code/autism_ipp_analysis.qmd
```

Each file also creates an HTML report documenting its steps.

## Workflow

| Step | File | Input | Output |
|------|------|-------|--------|
| 1. Recode | `autism_ipp_recode.qmd` | `Data/Original Data.xlsx` | `Data/autism_ipp_recoded.rds` |
| 2. Impute | `autism_ipp_imputation.qmd` | `Data/autism_ipp_recoded.rds` | `Data/autism_ipp_imputed.rds` |
| 3. Analyze | `autism_ipp_analysis.qmd` | `Data/autism_ipp_imputed.rds` | tables and figures in `Output/` |

## Output

The `Output/` folder holds results from the analysis, such as tables and figures.
These files are tracked in Git but can also be generated by running the script files above.
